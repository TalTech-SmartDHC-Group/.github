# TalTech Smart DHC Research Group

Welcome to our shared research workspace at Tallinn University of Technology (TalTech).

We share models, code, data, and tools related to smart district heating and cooling systems.

## Research Projects
Each project is maintained in a separate repository, with its own documentation and responsible contact person.

## Contributing
Group members contribute using their individual GitHub accounts.
Members with write access can upload, edit, and update repository files.

Each project should include:
- A README describing the model and how to use it
- Software requirements and example inputs, where applicable
- Links to related publications, if available
- The responsible person's name and contact details
- An appropriate license for shared materials

## Stable Links
Once a model or file is referenced in a publication, its published URL must remain valid. Coordinate any changes that could affect these links with the responsible person.
