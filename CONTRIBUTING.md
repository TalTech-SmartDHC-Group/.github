# Contribution Guide

## Access
Use your own GitHub account. Ask a group administrator for
write access to the relevant repositories.

Write access allows you to add, edit, and delete files.
Coordinate changes to other colleagues' work with them.

## Uploading Files
1. Open the relevant project repository.
2. Select Add file → Upload files.
3. Drag your files into the upload area.
4. Add a short commit message describing the changes.
5. Select Commit changes.

Upload only files and data that you have permission to share.
Never upload passwords, access tokens, or other credentials.

## Project README
Each project should include a README containing:
- Model name and purpose
- Required software and packages
- Instructions for running the model
- Example inputs, where applicable
- Links to related papers or DOIs, if available
- The responsible person's name and contact email
- License information

## Published Links
Once a model or file is referenced in a publication:
- Keep the repository name and referenced file paths unchanged.
- Do not delete the referenced files.
- Preserve the version used in the publication with a release
  or tag, and retain that version.
- Coordinate any necessary changes with the responsible person.

## Change History
Changes are recorded in the repository's commit history.
Use clear commit messages so colleagues can understand
what changed and why.
